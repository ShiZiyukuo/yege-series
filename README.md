# YeGe 系列

**教程学习与改造项目 · 持续开发中**

本仓库统一记录YeGe系列的学习、修改与实验。基础版由使用者根据教程自己手写；CodeBuddy和Codex在不同阶段协助修改。不同版本保留各自工程，不把AI协助或教程基础描述成全部从零原创。

## 打开与继续修改

使用团结引擎1.6.12 / 2022.3.61t13，从Hub添加需要的子工程目录。仓库根目录不是Unity工程。首次打开由编辑器恢复依赖与缓存。保留.meta，忽略Library、Build和日志。

新增后续版本可建yege4等目录并更新上表；修改现有工程正常提交，删除目录也能通过Git历史查看旧版。建议较大改动先建分支，验证后合入main，并用Issues记录待办。
